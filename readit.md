Factorial Calculator

A simple Python program that calculates the factorial of a fixed number using a "for" loop.

Description

This project contains a Python program that calculates the factorial of the number "5".

The program uses repeated multiplication to calculate the factorial.

How It Works

The program:

1. Sets the value of "n" to "5".
2. Initializes the factorial value as "1".
3. Uses a "for" loop from "1" to "n".
4. Multiplies the factorial value by each number.
5. Prints the final result.

Code Logic

n = 5
fact = 1

for i in range(1, n + 1):
    fact = fact * i

print(fact)
